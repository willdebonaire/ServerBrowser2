# user-scripts/

This folder holds **local-only** Playwright scripts written for individual
live browser sessions (form fills, submits, selectors, search harvesters,
etc.).

> **Nothing here is committed to the repository.** The scripts stay on the
> author's machine and are intentionally kept out of version control and off
> the public remote. The folder is tracked (via `.gitkeep`) only so its
> expected location is visible.

If you are looking for reusable, committed tooling, see [`scripts/`](../scripts)
and [`standalone/`](../standalone) instead.
