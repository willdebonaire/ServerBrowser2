ServerBrowser — Live Control Panel

A headed, real Google Chrome is running on this machine. You are seeing its screen. You can drive it live with Playwright over CDP, watch it here, and read data back — all without it ever closing.

Open VNC viewer →

1 · Overview

This session was started with npm run vnc. It runs:

  • Xvfb — a virtual display (:10)
  • Real Google Chrome (not Chromium) headed, persistent profile in profile/, with the DevTools port open
  • x11vnc + noVNC — this web view of the screen
  • CDP endpoint for live automation

Endpoints: VNC http://localhost:6080/novnc/vnc_auto.html · CDP http://127.0.0.1:9222/json/version

2 · Drive the live browser with Playwright

Attach to the already-running Chrome (never launches/closes it):

const { chromium } = require('playwright');
const browser = await chromium.connectOverCDP('http://127.0.0.1:9222');
const page = browser.contexts()[0].pages()[0];   // the visible tab

await page.goto('https://example.com');
const text = await page.evaluate(() => document.body.innerText);
console.log(text);

You can also page.click('a'), page.fill('input[name=email]', 'me@x.com'), await page.screenshot({path:'x.png'}), etc. Everything you do is visible in the VNC view above and your logins persist in profile/.

3 · One-line commands with npm run live

Quick commands that attach, act, and read — printing JSON:

npm run live -- goto https://example.com
npm run live -- dump
npm run live -- text
npm run live -- click 'button'
npm run live -- fill 'input[name=email]' me@x.com
npm run live -- screenshot /tmp/shot.png
npm run live -- eval "document.querySelectorAll('a').length"
CommandWhat it does
goto / reload / back / forwardnavigate the active tab
wait <ms> / waitfor <css>sleep / wait for an element
fill / type / click / press / keyboard / clearinteract with inputs & buttons
url / title / text / html / dumpread data off the page
eval '<js>'run any JS in the page, return the value
screenshot <file>save a screenshot
tabs / tab <i> / close-tabmanage open tabs (never closes the last one)

For long AI sessions, pipe JSON-lines: echo '{"cmd":"goto","args":["https://x.com"]}' | npm run live -- --stdin

4 · Run existing stored scripts on this live browser

Re-run your stored scripts against this same visible instance, over and over, without it ever closing:

npm run live-run -- batch.js codes.csv
npm run live-run -- dataforthai.js some-arg

live-run redirects the script's chromium.launch() to attach to this browser and suppresses browser.close() — so the VNC view, cookies and logins all survive every run.
